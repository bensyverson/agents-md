## Testing and timing

1. **Assert outcomes, not wall-clock time — and size budgets passed into code for a loaded machine.** A parallel test suite under load can delay a short `sleep` by many seconds, so "returned in under N seconds" fails for reasons unrelated to the code. Assert the typed error or the on-disk state; if you must bound time, bound it at "not hung" scale (tens of seconds). The same applies to a timeout argument or poll bound handed *into* the code under test, which fails looking like a product bug; and a poll loop must look at its condition once more after the deadline, or a late wake-up reports a timeout nothing earned. — **swift** (or a testing module) — 2026-08-29
2. **A timing taken while other builds run is not a timing.** Concurrent compiles on the same machine inflated an unchanged suite several-fold. Re-measure before treating a recorded figure as a premise, quote the minimum of several runs, and say in the write-up whether the machine was loaded. — **docs** (figures) — 2026-08-29
3. **A wait placed after an irreversible step tests nothing.** If a test navigates away, tears down or swaps a page before the state it is waiting for was written, no amount of waiting afterwards recovers it; a generous bound only delays reporting a race already lost. Bound the wait on the state the later step consumes, before taking the irreversible step. — **core** (testing) — 2026-08-31
4. **A test that reads a short-lived UI flash is reading the machine.** A poll can easily take longer than a 1-second visual state under load. Have the page record the fact as it happens (an observer setting a flag) and assert the flag afterwards. Headless browsers also own no real clipboard or focus; stub that seam and assert what the handler did with it. — **core** (testing) — 2026-09-07
5. **"Did the page reload?" cannot be asked of a back navigation.** The browser's back/forward cache restores the previous document with its JavaScript heap, so a marker on `window` survives a real reload. Prove the forward step was in place first, in the same test; then back is a history pop by construction. — **core** (testing, web) — 2026-08-30
6. **When a test helper and production do "the same thing" through different APIs, the difference is the bug.** A test setup that took one path while production took another let thousands of green tests miss a production failure. Make fixtures go through the production path. — **core** (testing) — 2026-08-30
7. **"The compiler accepted it" is evidence only from a build that otherwise succeeds.** Type checking stops at the first errors, so later passes (e.g. sendability) never run on a red build; "no error at line N" says nothing about line N. Get to green first, or say plainly the observation is unverified. — **swift** — 2026-09-07
8. **Swift Testing charges a test from when it was queued.** All tests are started up front, so a cluster of trivial tests reporting the same long duration is a queue, not slowness. Find what the run waits on from CPU time and sampling instead. — **swift** — 2026-09-28
9. **Run every test suite under a watchdog, and know macOS has no `timeout`.** A wedged run sits at 0 % CPU forever with its agent waiting. `perl -e 'alarm <s>; exec @ARGV' <cmd>` is a portable bound; it kills the runner, not necessarily the test host process, which may be reparented and must be found and killed by pid. Sample it before killing. — **harness** — 2026-09-26

## Swift toolchain and SwiftPM

10. **`swift test --filter` matches the Swift identifier, not the display name.** It is a regex over `Type/function`, and a filter that matches nothing still prints a passing run of zero tests. Filter on type or function names. — **swift** — 2026-08-30
11. **Editing a source file while `swift build`/`swift test` runs aborts the build.** SwiftPM fails with "input file was modified during the build", which under `--quiet` surfaces only as a bare `fatalError` minutes later. Treat a running build as a lock on the checkout; batch edits between runs. — **swift** — 2026-08-29
12. **`--quiet` hides a compile error behind a bare `fatalError`.** Rerun without `--quiet` and strip ANSI color before grepping for `.swift:<line>:<col>: error`. Low disk space produces similar noise; check free space too. — **swift** — 2026-09-28
13. **A signature or enum-layout change can leave SwiftPM linking stale objects.** Changing a public return type, or adding a case to an enum another module stores as `Optional`, can leave dependent test objects uncompiled: link errors naming old types, or "impossible" assertion failures in untouched suites. `touch` the consuming files and rebuild; a fresh checkout being green is the tell. — **swift** — 2026-08-31
14. **`swift build -c release --build-tests` cannot build tests that use `@testable import`;** `swift test -c release` can. Use the latter (with a filter matching nothing) to warm a release test build. — **swift** — 2026-09-27
15. **A hand-rolled multi-file `swiftc` needs `-wmo`.** Without it, each of N files starts a frontend that re-parses the whole module, so cost grows with files × module size — easy to misread as slow-to-type-check code. Profile with `-Xfrontend -warn-long-function-bodies=<ms>` before blaming the code. — **swift** — 2026-09-28
16. **Release-only crashes in the test build can be a miscompile.** SwiftPM builds library targets whole-module but the release test target without it, so a test-only `-O` crash with an impossible stack may be the compiler. One observed shape: a `var` declared without an initializer, assigned in a loop, whose type mixes a class with a generic parameter. Restructure so each value is consumed where it is made, and keep a probe script that says whether the toolchain still needs it. — **swift** — 2026-08-30
17. **Swift Testing macros cannot nest:** `#require` inside `#require` (or inside `#expect`'s interpolation) fails with "recursive expansion of macro", pointing inside the expansion. Hoist the inner one to its own `let`. — **swift** — 2026-08-29
18. **A raw string holding hex colors needs two hashes.** `#"…"#` ends at the first `"#` inside, e.g. `"#fff"`; use `##"…"##`. The compiler's "expected ',' separator" points elsewhere. — **swift** — 2026-09-08
19. **`Task.detached` inside a function with an `isolated` parameter may not compile** ("pattern that the region-based isolation checker does not understand"). Hoist the detach into a plain `nonisolated static` helper one call out. — **swift** — 2026-09-07
20. **Blocking on a semaphore in a synchronous Swift Testing test can starve the callback it waits for.** The test body and `DispatchQueue.global()` share limited threads; await a continuation instead of gating an async callback behind a synchronous wait. — **swift** — 2026-08-30
21. **A timer on a Task or a global queue cannot fire while the cooperative pool is saturated.** Both share the pool's thread limit, so a deadline built on them silently stops bounding anything. Fire deadlines from a private serial `DispatchQueue(label:)`, which gets an overcommit thread. — **swift** — 2026-09-28
22. **A wedged process whose stack sample holds none of your frames is a suspended `await`** — or a merely slow phase whose tasks are sleeping. A suspended task has no thread and no stack; the frames you do see are whatever is still polling. Look at what the test was waiting for, and re-run with a longer watchdog before calling it a hang. Corollary: an `await` on a callback you do not own needs a deadline you do. — **swift** — 2026-08-31
23. **A deep recursive walk over a tree of values overflows a task's stack in debug builds.** A Swift task thread has ~512 KiB and debug builds give each temporary its own stack slot; the process dies of SIGBUS with no output, while the same command under a debugger (8 MiB main thread) passes. Walk from a work list; remember that freeing, synthesized equality and encoding of an `indirect` tree also recurse. — **swift** — 2026-09-26
24. **`CGRect.width`/`.height` are standardized (absolute).** A rect built with a negative width is not empty; test scalar widths before building the rect. — **swift** — 2026-09-27
25. **Core Text: register fonts from file URLs, not from data.** Descriptors created from data carry no URL and registration rejects them, reporting only to an optional handler. Write bytes to a temp file if needed. Registration is process-global and irreversible, so only one test per run may observe a family going from absent to present. — **swift** — 2026-08-30
26. **Core Image renders through Metal even with the software-renderer option**, so with no reachable GPU (sandboxes, headless machines) `createCGImage` returns nil and a guarded effect becomes a silent no-op. Use a CPU path (e.g. Accelerate) for anything that must work headless. — **swift** — 2026-09-26
27. **`FileManager.default.temporaryDirectory` ignores `$TMPDIR` on macOS.** It resolves to the per-user `/var/folders/…/T`, which a sandbox that allows only `$TMPDIR` denies — while tests run unsandboxed and pass. Honor `$TMPDIR` explicitly. — **harness** / **swift** — 2026-09-26
28. **`cp` over an installed, ad-hoc-signed macOS binary gets it SIGKILLed** (silent exit 137) because the inode was rewritten under its signature. `rm` the target first or `mv` the new one in. — **swift** — 2026-08-31
29. **DocC refuses reciprocal Topics entries and cannot link a sibling module's symbols** from a single-target catalog. Link the reciprocal page from prose; name sibling-target types in code voice. The coverage flag is `--coverage-summary-level brief`. Baseline the warning count before judging a change. — **docs** / **swift** — 2026-09-08
30. **swiftformat in a worktree under a dot-directory prints "Ignoring config file" even when `--config` is passed and used.** Verify by the skipped-file count, not that line. — **harness** — 2026-09-02

## Harness

31. **A `kill -0` liveness poll inside a sandboxed monitor reports a live process as gone.** The sandbox makes `kill -0` fail regardless of the process, so a wedged run reads as finished. Poll with `ps -p <pid>` in a normal shell call, or run the suite in the foreground under a watchdog with verbose output to a log. — **harness** — 2026-09-08
32. **The worktree guard refuses more than its documented triggers.** Seen refused: any command naming a path that contains `/git/`, interpreter heredocs, compound commands with `--package-path`, and any command containing the word `eval`. What always worked: write a small script with the file-writing tool and run it as one plain call. — **harness** — 2026-09-26
33. **In the sandbox, Apple's TLS stack cannot verify any certificate** (the trust daemon is denied unless the weaker-network-isolation setting is on), and there is no DNS, so a local proxy must be dialed by IP. `URLSession` HTTPS fails as "certificate untrusted" — it looks like a MITM, but `curl` (LibreSSL) sees the real chain. A curl fallback is a viable workaround. — **harness** — 2026-09-26
34. **Permission checks can stall with no verdict.** An agent can hit many calls in a row on which the auto-mode classifier returns nothing; retries don't help. Briefs should say "if permission checks stall repeatedly, stop and report what's left", and the integrator should expect to finish such a branch. — **harness** — 2026-09-28
35. **Synthetic CPU load outlives the agent that started it,** and the editor's language server is a second hidden load (it typechecks every file an agent edits, in every worktree). Never generate synthetic load in a brief — parallel agents building *is* the loaded machine; if unavoidable, bound the burner by itself (`perl -e 'alarm 300; exec "yes"'`), never by a cleanup step. Find stray load with `ps -Ao pid,ppid,pcpu,args -r | head`. — **harness** — 2026-09-27

## Delegation and jobs

36. **Cap parallel cold builds.** Ten agents starting cold Swift builds together panicked a 16 GB laptop (watchdog timeout), killing every agent. Cap concurrent build-heavy agents (about five on such a machine), pass a low `-j` to each, and stagger dispatch so first builds don't coincide. — **delegation** — 2026-09-26
37. **A message to a finished subagent restarts it.** Sending to an agent that already handed back resumes it, possibly after its worktree is gone. Send a finished agent nothing unless you want it working again; stop a restarted one explicitly. — **delegation** — 2026-09-26
38. **A forked "research only" subagent edits and commits anyway.** A fork inherits the parent's full plan and tools, so prose limits don't hold it. Use a fresh read-only search agent for research, forbid forking for research in every brief, and put "never commit" in any brief an agent writes for its own helpers. — **delegation** — 2026-09-26
39. **A subagent the user stopped cannot be resumed — relaunch it from its trail.** Condense the stopped agent's transcript into its messages and tool calls, save it in the scratchpad, and brief a fresh agent to read that trail and the worktree's diff and continue. — **delegation** — 2026-09-27
40. **The briefing template's bare claim expires under a working agent.** A default 30-minute claim, extended only by tracker writes, lapses while an agent builds and tests for an hour or more, so the tracker misreports who is working. Put a duration in the template's claim line (several hours); the durable fix is a liveness-bound claim in the tracker itself. — **delegation** / **jobs** — 2026-09-26
41. **The integrator cannot close a leaf an agent still claims.** A finished agent's claim outlives its report, and closing fails until it is released under the agent's identity. Either have agents `release` as the last step before handing back, or document that the integrator releases as the agent first. — **jobs** — 2026-09-27
42. **A docs-only commit does not need the test suite.** "Run the full suite before every commit" is for commits that can change behavior; the pre-commit hook still runs. — **core** — 2026-08-31

## CLI design

43. **A verb that never exits must flush stdout itself.** Redirected output is block-buffered, so a long-running server's "here is my URL" line sits in the buffer and `cmd | head -1` hangs; every other verb gets away without flushing because it ends. — **cli-design** — 2026-08-29
44. **Refuse when the result would be wrong; hint when it is right but suboptimal.** A typo or missing target exits non-zero with a near miss, and a named flag opts into creating it; a stricter-than-needed token is accepted with a stderr hint. Near misses come from edit distance on the misspelled segment — for paths, property keys, subcommands and enum values. — **cli-design** — 2026-10-10
45. **Text-table cell encoding:** a cell containing whitespace is JSON-quoted, `-` means absent, and a literal `-` is quoted. Still open for ruling: one revision token labeled by scope, capped lists in error messages, and whether "a write answers with what it made" covers files. — **cli-design** — 2026-10-10
46. **An argument parser may have no way to express "option whose value may be omitted."** If a flag must accept being written bare, fill the value in before the parser sees the argument vector, and state the fill-in in the option's own help. — **cli-design** — 2026-08-31
